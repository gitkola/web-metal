# TONMET Metal calculator

TONMET Metal calculator is a web application that allows users to calculate the weight, length, cost, and other parameters of metal profiles, sheets, pipes, etc.
User also can send the order.

TONMET Web App: [https://gitkola.github.io/web-metal/](https://gitkola.github.io/web-metal/)
TONMET Privacy Policy: [https://gitkola.github.io/web-metal/#/privacy-policy-web](https://gitkola.github.io/web-metal/#/privacy-policy-web)
